## Sobre o projeto

Análise exploratória do dataset [Procrastination Habits and Behaviors Data](https://www.kaggle.com/datasets/manaswinsripatnala/procrastination-habits-and-behaviors-data), com o objetivo de investigar fatores associados à procrastinação.

## Entrega

O notebook inclui:

- carregamento e preparação dos dados;
- criação dos índices de procrastinação e autorregulação;
- visualizações e análise dos resultados;
- respostas das perguntas de pesquisa e conclusão final.

## Tecnologias

- Python
- Pandas e NumPy
- Matplotlib e Seaborn
- KaggleHub
- Jupyter Notebook

## Como executar

Instale as dependências:

```bash
pip install notebook pandas numpy matplotlib seaborn kagglehub
```

Inicie o Jupyter:

```bash
jupyter notebook
```

Abra `analise_procrastinacao.ipynb` e execute as células em ordem. O dataset será baixado automaticamente pelo KaggleHub.
